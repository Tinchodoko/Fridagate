# AI review smoke test

Este archivo es temporal y existe únicamente para comprobar que los revisores automáticos de Pull Requests están integrados correctamente.

## Alcance

- No cambia el código de la aplicación.
- No cambia la configuración de compilación.
- No debe fusionarse en `main`.

## Qué revisar

Confirma si la descripción es clara, si el alcance coincide con el contenido y si detectas algún riesgo o problema real. Evita inventar defectos cuando no haya ninguno.
